EMI by hand (the standard loan formula)
   monthly rate r = 14% / 12 / 100          = 0.011667
   growth (1 + r)^24                        = 1.32099
   EMI = P * r * growth / (growth - 1)      = 300,000 * 0.011667 * 1.32099 / 0.32099 = 14,403.86
   (sanity: 24 payments of ~14,404 = ~345,700 -> about 45,700 of interest on a 300,000 loan)

LOG TRANSFORM: log(1 + income) pulls an extreme value back towards the others
   income      : ['300,000', '450,000', '600,000', '900,000', '6,000,000']
   log(1+inc)  : [12.61, 13.02, 13.3, 13.71, 15.61]
   biggest/median = 10.0x on the raw scale, but only 2.30 log units above the median.

MEDIAN IMPUTATION (learned on TRAIN only) + MISSING INDICATOR
   train values [10.0, 20.0, 90.0, nan] -> median of the observed values = 20.0  -> NaN becomes 20.0
   income_missing = 1 for that row: the model can still learn that 'did not report income' is informative.
   The API does exactly the same: annual_income omitted -> NaN -> engineer() -> same Pipeline -> same median.

STANDARDIZATION z = (x - mean) / std  (mean and std also learned on TRAIN only)
   x = [2.0, 4.0, 6.0]  mean = 4.0  std = 1.6330  ->  z = [-1.225, 0.0, 1.225]
   After this every coefficient reads 'change in log-odds of default per +1 standard deviation' -> comparable and explainable.
