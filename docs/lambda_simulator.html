Box-Cox only works on strictly positive data (every value must be > 0). It finds one power, λ, that reshapes a skewed distribution into something closer to symmetric. This dataset: 400 simulated "batch fee revenue" values — realistically right-skewed, always positive.

Yeo-Johnson works on any real values — positive, negative, or zero. Same idea as Box-Cox, but defined piecewise so negative numbers don't break it. This dataset: 400 simulated "monthly profit margin" values — some batches genuinely lose money.
1.00 no transform (identity)
Yeo-Johnson(x, λ)  =  for x≥0: ((x+1)^λ − 1)/λ  |  for x<0: −((−x+1)^(2−λ) − 1)/(2−λ)
